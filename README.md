Meridian Enterprise Infrastructure

Project Overview

This project simulates the design, implementation, security, and administration of the IT infrastructure of Meridian IT Solutions, a fictional company.

The lab combines Cisco Packet Tracer network simulations with a virtualized Windows Server 2022 environment and Windows 11 Pro clients.

 Objectives

- Design and implement a segmented enterprise network.
- Configure switching, VLANs, routing, and access control.
- Deploy Windows Server 2022 infrastructure services.
- Implement Active Directory, DNS, DHCP, and Group Policy.
- Apply least-privilege access controls and departmental file permissions.
- Automate repeatable administrative tasks using PowerShell.
- Validate functionality and document troubleshooting scenarios.

Lab Environment

- Cisco Packet Tracer
- Oracle VirtualBox
- Windows Server 2022
- Windows 11 Pro
- PowerShell
- Git and GitHub

Repository Structure

- `docs/` — Business requirements, architecture, addressing plans, and test plans.
- `packet-tracer/` — Network simulation files and device configurations.
- `windows-server/` — Server deployment notes and administration documentation.
- `powershell/` — Administrative automation scripts.
- `screenshots/` — Implementation evidence.
- `troubleshooting/` — Failure scenarios, diagnostic steps, and resolutions.
